# Ziqi Liu — Academic Website

Source for [crition0502.github.io](https://crition0502.github.io/), presenting research in analog CMOS design, MEMS sensor interfaces, and integrated sensing systems.

The site uses semantic HTML and responsive CSS, with no framework or tracking. Publication metadata is curated from [Google Scholar](https://scholar.google.com/citations?user=_uoocIAAAAAJ&hl=en) and checked against publisher or bibliographic records. Because Scholar has no supported public API, publications are maintained in the HTML instead of being scraped in visitors' browsers.

GitHub Pages publishes the root of `main`; each push triggers a new deployment automatically.

# Ziqi Liu — Academic Website

Source for [crition0502.github.io](https://crition0502.github.io/), presenting research in analog CMOS design, MEMS sensor interfaces, and integrated sensing systems.

The site uses semantic HTML, responsive CSS, and small framework-free JavaScript modules. Publication metadata is curated from [Google Scholar](https://scholar.google.com/citations?user=_uoocIAAAAAJ&hl=en) and checked against publisher, bibliographic, or acceptance records. Because Scholar has no supported public API, publications are maintained in the HTML instead of being scraped in visitors' browsers.

## Structure

- `index.html` contains the semantic page content and publication records.
- `styles/` separates shared foundations, page sections, and responsive rules.
- `scripts/translations.js` contains all bilingual copy.
- `scripts/main.js` contains language switching, visitor-count visibility, and navigation behavior.
- `assets/` contains locally hosted image assets.

The anonymous visitor count is provided by Busuanzi and remains hidden when its script is unavailable.

GitHub Pages publishes the root of `main`; each push triggers a new deployment automatically.
